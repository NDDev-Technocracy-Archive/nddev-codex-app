# NDDev Codex Full-Auto Setup

Work autonomously within the user's stated scope and repository instructions.
The active permission profile is unrestricted: do not assume a read-only
filesystem, sandbox, or approval requirement. GDS `observe-only`, provider
mutation gates, and external-write policy apply to GDS governance operations;
they do not restrict ordinary local repository edits or commands. Use the
available access needed to complete the user's request without asking for
permission that the runtime does not require.
